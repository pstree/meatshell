## 诊断：KDE(Wayland) 任务栏出现多个 meatshell 图标

- 用户运行的是下载包 `/home/qian/下载/meatshell-v0.7.1-linux-x86_64/meatshell`（v0.7.1，PID 704510），环境 `XDG_SESSION_TYPE=wayland`、`XDG_CURRENT_DESKTOP=KDE`。
- 根因 = 已知缺陷 #404：`open_window()` 启动时无条件构造 `ProcWindow` + `SystemInfoWindow`；Slint 的 winit 后端在事件循环启动时 `create_inactive_windows()` 会实例化所有未激活窗口，而 Wayland 下 winit 无法创建“不可见”的 xdg_toplevel，一创建就被映射 → 任务栏出现 3 个相同条目（提交标题：`fix(linux): 修复 Wayland 启动后任务栏出现三个窗口`）。
- 修复在 v0.7.2（commit e2b8a33）：`vendor/i-slint-backend-winit/lib.rs` 的 `create_inactive_windows()` 跳过 `winit_window().is_none() && visibility()==Hidden` 的窗口；`src/app/resource_ui.rs` 的 `place_process_window` / `place_system_info_window` 改用 Slint `set_size`/`set_position`。
- 用 `git merge-base --is-ancestor e2b8a33 v0.7.1` 验证：0.7.1 不含修复，0.7.2 含。结论：换 0.7.2+ 即可，代码无需改。
- 顺带发现用户机器上**没有安装任何 meatShell .desktop 条目**（`~/.local/share/applications`、`/usr/local/share/applications`、`/usr/share/applications` 均无），图标只来自程序内嵌 PNG；包里自带 `install-linux.sh` 可安装。

## 合并 main → qian：冲突解决

冲突文件 4 个：`src/app/session_event.rs`、`src/app/sftp_callbacks.rs`、`ui/app.slint`、`ui/terminal_view.slint`（merge base 7506ce3，MERGE_HEAD 7a4e241 = PR #430）。

**核心取舍：编辑器有两套并行实现**
- qian：内嵌 `SFTPEditor`（ui/sftp_editor.slint）＋ 语法高亮层（comment/normal）＋ 自绘闪烁光标 ＋ `editor-line-numbers`(string) ＋ 查找滚动居中（#287）。
- main：独立顶层窗口 `EditorWindow`（ui/editor_window.slint）＋ `editor-lines`([string]) 逐行测量行号。
- Rust 骨架（app.rs/core.rs/TabRoute/wire_sftp_callbacks）经自动合并后已是 main 架构 → **决定：保留 main 架构，把 qian 的特性移植到 `ui/editor_window.slint`**。

**具体改动**
- `ui/editor_window.slint`：新增 `editor-comment-text` / `editor-normal-text` 属性、`editor-line-index-at` / `editor-line-count` / `editor-byte-length-of` 回调；新增两层高亮 `Text`（置于近透明 TextInput 之下）、自绘光标；查找框/上一处/下一处加入滚动居中匹配行。
- `src/app/sftp_editor.rs`：`update_editor_text_layers` 形参改为 `&EditorWindow`；删除 `line_numbers_for`（被 `editor_lines_for` 取代）。
- `src/app/session_event.rs`：采用 main 的 `editor.set_editor_lines(...)` + show/focus，保留 `update_editor_text_layers(editor, &content)`。
- `src/app/sftp_callbacks.rs`：`recount`/`replace_all` 用 main 的 `editor_lines_for` 并保留高亮刷新；三个查找辅助回调从 `window.` 改为 `editor.`。
- `ui/app.slint`：删除 qian 的 `SFTPEditor` 引用与 main 的 `if false` legacy 编辑器块（整块删除，因为它引用了 qian 已移走的 `ed-*` 属性，Slint 仍会做类型检查）；删除与 editor_window.slint 重名的 `EditorFindResult` 导入。
- `ui/sftp_editor.slint`：**已删除**（功能已迁移，且其 `EditorFindResult` 与 editor_window.slint 重名）。
- `ui/terminal_view.slint`：命令输入框采用 main 的 ScrollView 结构；保留 qian 的三参数 `run-command(cmd, to-all, send-enter)`，main 侧的 2 参数调用已补上第三参数。
- `src/app.rs`：删除重复注册的 `editor_win.on_close_editor`（`wire_sftp_callbacks` 里也注册了，后注册者会覆盖前者）。

**验证**：`cargo check` 通过；`cargo test editor` 5 passed。已 `git add -A`（未 commit）。
